## 👨‍💻 About me

I'm a B.E. student at Vidyavardhini's College of Engineering and Technology (VCET), graduating in 2027. I like the part of machine learning that sits *around* the model: how it gets checked, served and trusted once it has to do something real.

- 🔭 **Right now:** building **[TrustLayer](https://github.com/ahmadaquib/TrustLayer)**, my final-year project. It checks what an AI agent *believes* and what it's *allowed to do* before any action runs.
- 📄 **Published:** co-authored an IEEE paper on predicting the energy, carbon and cost of code.
- 🎯 **Looking for:** Python / ML engineering roles for the 2027 batch.
- 🌱 **Working on:** SQL, data structures and algorithms, and explaining my own projects clearly.
